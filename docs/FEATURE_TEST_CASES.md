# Reading Quiz 功能测试用例

本文档覆盖本次实施的核心功能测试场景，可在云构建产物（APK/AAB）安装后逐条验证。

---

## 一、笔记浮窗（NotePadWindow）

### TC-NP-001：打开笔记浮窗
**前置条件**：进入任意文章阅读页
**步骤**：
1. 点击底部 ⚙ Edit（记笔记）图标
2. 在弹出菜单中选择「新建笔记」

**预期**：
- 弹出便笺浮窗（浅米黄纸张背景）
- 浮窗位于屏幕右下角（距右 24dp，距底 120dp）
- 标题显示「便笺」
- 编辑区为空，显示占位文字「在这里输入笔记…」

**ADB 验证**：`adb logcat -s NotePad:V` 应输出 `NotePadWindow open: articleId=xxx, existing=0`

---

### TC-NP-002：拖拽移动浮窗
**前置条件**：笔记浮窗已打开
**步骤**：
1. 按住顶栏的 ⋮⋮（DragIndicator）图标
2. 向屏幕左上角拖动 200dp

**预期**：
- 浮窗跟随手指移动
- 释放后浮窗停留在新位置
- 拖动过程中不会触发关闭或编辑

**边界测试**：
- 向屏幕左边缘拖动：浮窗应停在左边缘（不超出屏幕）
- 向底部拖动：浮窗应停在底部
- 极小位移（<5dp）：不触发拖拽（避免误触）

---

### TC-NP-003：文本输入
**前置条件**：笔记浮窗已打开
**步骤**：
1. 点击编辑区
2. 使用输入法输入「Hello World」

**预期**：
- 文本实时显示在编辑区
- 光标颜色为 Accent（咖啡棕）
- 软键盘弹出时浮窗位置不变（不阻塞输入）

---

### TC-NP-004：加粗选中文本
**前置条件**：笔记浮窗已打开，已输入文本
**步骤**：
1. 输入「这是普通文本，这是重要」
2. 长按「重要」二字 → 选中
3. 点击工具栏 **B**（FormatBold）图标

**预期**：
- 「重要」二字变为 Bold 字重
- 选区保持不变（仍选中「重要」）
- 再点一次 **B**：取消加粗

**ADB 验证**：`adb logcat -s NotePad:V` 应输出 `note saved: ... boldSpans=1`

---

### TC-NP-005：保存笔记
**前置条件**：笔记浮窗已输入文本
**步骤**：
1. 输入「Test Note」
2. 点击「保存」按钮

**预期**：
- 编辑区文本清空（恢复到占位文字）
- 浮窗底部「已存 N 条」计数 +1
- 关闭浮窗后重新打开，原笔记出现在历史列表中
- ReadingRepository.notes 包含新笔记（id 为 UUID）

---

### TC-NP-006：删除已有笔记
**前置条件**：已保存至少 2 条笔记
**步骤**：
1. 打开笔记浮窗
2. 历史列表中点击某条笔记右侧的 🗑 删除图标

**预期**：
- 该笔记从历史列表立即消失
- 计数 -1
- 关闭浮窗后再次打开：笔记不再出现
- ReadingRepository.notes 不包含该 id

---

### TC-NP-007：关闭浮窗
**前置条件**：笔记浮窗已打开
**步骤**：
1. 点击右上角 ✕ 关闭按钮

**预期**：
- 浮窗消失
- 笔记内容**保留**（不丢失未保存的输入）
- 再次点击 Edit → 新建笔记：输入框仍为空（仅未保存内容丢失）

## 三、答题页集成

### TC-QZ-001：答题页笔记入口可见
**前置条件**：进入任意答题页
**步骤**：
1. 查看底部操作区

**预期**：
- 原有 Bookmark（标记疑问）图标存在
- 新增 Edit（记笔记）图标在 Bookmark 右侧
- 两者均为透明背景、36dp 尺寸
- 未触发时 tint 为 CafeColors.Muted（柔和灰色）

---

### TC-QZ-002：答题中记录笔记
**前置条件**：答题页第 3 题
**步骤**：
1. 点击 Edit 图标 → 弹出菜单 → 「新建笔记」
2. 在浮窗中输入「需要复习 Kotlin 协程」
3. 点击「保存」
4. 关闭浮窗 → 继续答题

**预期**：
- 笔记已保存到当前 articleId
- 答题流程不被中断
- 提交答卷后回到首页 → 进入该文章 → 笔记浮窗打开 → 历史包含「需要复习 Kotlin 协程」

## 五、回归测试

### TC-RG-001：原有功能不受影响
**步骤**：
1. 进入首页 → 文章列表正常显示
2. 点击文章 → 阅读页正常加载章节
3. 滚动到底部 → 点击「进入答题」→ 答题流程完整
4. 答题页 Bookmark 功能仍可用
5. 沉浸模式切换正常
6. AI 设置页模型获取、测试连接功能正常

**预期**：所有原有功能行为不变。

---

### TC-RG-002：性能影响
**步骤**：
1. 反复打开/关闭笔记浮窗 20 次
2. 反复拖拽浮窗 10 次

**预期**：
- 无明显卡顿（FPS ≥ 50）
- 无内存泄漏（`adb shell dumpsys meminfo` 中 ReadingQuiz 内存不持续增长）
- 关闭浮窗后无残留 UI
